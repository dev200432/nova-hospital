
# 🏥 Nova Hospital - Full Stack Healthcare Web Application

Nova Hospital is a comprehensive hospital management and healthcare web application built using **Python (Django)** and **MySQL**. It features a dynamic frontend for patients and a robust administrative backend for managing hospital operations.

---

## 🚀 Key Features

* **Patient Appointment System:** Seamless online appointment booking for patients.
* **Departments Management:** Detailed view of medical departments (Cardiology, Pediatrics, Internal Medicine, etc.).
* **Doctor Profiles:** Showcase expert doctors with qualifications, experience, and department mapping.
* **Services Section:** Highlights 24/7 emergency care, advanced diagnostics, and other medical services.
* **News, Media & Blog Section:** Admin-managed updates, healthcare tips, and hospital announcements.
* **Django Admin Panel:** Secure backend dashboard to easily manage database entries, doctors, departments, and content.

---

## 🛠️ Tech Stack

* **Backend:** Python 3.14, Django 6.1
* **Database:** MySQL 8.0
* **Frontend:** HTML5, CSS3, JavaScript
* **Media Handling:** Pillow
* **Deployment Ready:** Gunicorn, WhiteNoise, Render support
